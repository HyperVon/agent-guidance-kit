# Acme checkout release candidate

Acme is a small online retailer moving its two-item checkout to a new release.
The page is used by customers on phones and laptops while they enter contact
and payment details, review the order, and submit a purchase.

The product brief supports 390px phones, 768px tablets, and 1440px desktop
screens. A successful purchase should make the outcome clear, and a customer
who needs to correct details or retry a declined payment should be able to
recover without losing their place.

The repository contains the source snapshot, a local payment stub, a small
smoke check, and release notes. The payment stub is for local development and
is not evidence of a production payment integration. No rendered browser trace
or live service is included in this snapshot.
