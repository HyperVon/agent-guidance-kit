# Skill Catalog

Neutral inventory of the guidance skills available in this repository. Used to
route a request to the skill that owns the relevant step.

1. **adversarial-pr-review** — Evaluate a pull request from a critical,
   adversary-minded perspective to surface risky changes.
2. **ai-slop-detector** — Identify low-value, templated, or low-effort AI-generated
   content in code or docs.
3. **architecture-review** — Review system and module architecture for structural
   and design concerns.
4. **code-review** — Find defects and produce review findings on a diff or branch.
5. **codebase-orientation** — Build a map of an unfamiliar codebase to support
   navigation and change.
6. **dependency-upgrade** — Assess and plan upgrades of third-party dependencies.
7. **documentation-review** — Review documentation for accuracy, clarity, and
   completeness.
8. **frontend-quality-review** — Review frontend code for quality, accessibility,
   and UX concerns.
9. **git-github-workflow** — Guidance for git and GitHub branch, review, and
   release workflows.
10. **harness-adaptation** — Adapt agent guidance to a specific harness or runtime.
11. **implementation-planning** — Turn a resolved design into a concrete
    implementation plan.
12. **parallel-multi-agent** — Coordinate multiple agents working in parallel on a
    task.
13. **quality-hardening** — Improve robustness, error handling, and reliability of
    code.
14. **reduce-code-size** — Shrink and simplify code while preserving behavior.
15. **repository-guidance-authoring** — Author guidance material for a repository.
16. **requirements-and-design** — Capture and structure requirements and design.
17. **review-feedback-resolution** — Receive review findings and disposition each
    item; apply only accepted fixes.
18. **rules-and-skills-audit** — Audit the repository's rules and skills for
    consistency and coverage.
19. **security-review** — Find security defects and produce security findings.
20. **skill-authoring** — Author a single standalone skill.
21. **skill-discovery** — Discover and select the right existing skill for a need.
22. **skill-evaluation** — Evaluate a skill's behavior against expected outcomes.
23. **skill-optimizer** — Improve an existing skill's precision and usefulness.
24. **skill-reviewer** — Review a skill for quality and correctness.
25. **systematic-debugging** — Locate and fix defects through a structured process.
26. **threat-modeling** — Model threats and attack surfaces for a system.
