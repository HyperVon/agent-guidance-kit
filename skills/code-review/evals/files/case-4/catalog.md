# Skill catalog

Available skills in this workspace, with a one-line summary of what each one
owns.

| Skill | Summary |
| ----- | ------- |
| `adversarial-pr-review` | Multi-agent adversarial review of a pull request with independent reviewers and convergence passes. |
| `ai-slop-detector` | Broad artifact-quality audit for plausible-looking but low-value code, tests, and documentation. |
| `architecture-review` | Fresh-eyes architecture review comparing Keep, Evolve, Replace, and Greenfield options for a system or subsystem. |
| `code-review` | Evidence-based review of a diff, branch, or subsystem for concrete correctness, contract, security, and test defects. |
| `codebase-orientation` | Map an unfamiliar repository and explain how it works for onboarding. |
| `dependency-upgrade` | Plan and execute dependency version bumps with risk grouping and verification gates. |
| `documentation-review` | Check documentation against current source, build, and CI truth and update stale claims. |
| `frontend-quality-review` | Review an implemented UI surface for interaction, accessibility, responsive, and state defects. |
| `git-github-workflow` | Branch, commit, push, pull-request, and release hygiene for Git and GitHub. |
| `harness-adaptation` | Make repository guidance discoverable by a specific coding harness without duplicating it. |
| `implementation-planning` | Turn settled requirements or design into an execution-ready implementation plan. |
| `parallel-multi-agent` | Split a large task into bounded concurrent workers with disjoint ownership and parent-owned integration. |
| `quality-hardening` | Bounded QA loop: baseline, regression tests first, minimal fixes, re-run gates. |
| `reduce-code-size` | Shrink or split code while preserving behavior and verification. |
| `repository-guidance-authoring` | Write or improve a repository's canonical agent guidance files from repository evidence. |
| `requirements-and-design` | Clarify desired behavior, constraints, and acceptance criteria, then choose a design approach. |
| `review-feedback-resolution` | Disposition incoming review comments or findings and apply only the accepted ones. |
| `rules-and-skills-audit` | Audit a guidance set for overlap, conflicts, unclear triggers, and consolidation opportunities. |
| `security-review` | Review a change or system for evidence-backed security risk in secrets, identity, authorization, and input handling. |
| `skill-authoring` | Author or revise a repository-local skill after approval, preserving triggers and boundaries. |
| `skill-discovery` | Search public sources for candidate agent workflows and map them to the local skill catalog. |
| `skill-evaluation` | Design or run clean-context evaluations that compare a skill against no-skill or prior-version behavior. |
| `skill-optimizer` | Reduce the context cost of guidance without weakening routing, safety, or verification. |
| `skill-reviewer` | Review a skill's content for missing, weak, or misleading guidance and recommend improvements. |
| `systematic-debugging` | Find the root cause of a reproducible failure before proposing a fix. |
| `threat-modeling` | Build a repository-grounded threat model: assets, actors, trust boundaries, abuse paths, mitigations. |
